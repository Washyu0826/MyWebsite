# 限時分享連結

把素材庫裡某一個版本的原始檔，用一條有期限的網址分享出去。對方不需要登入，你可以隨時撤銷。典型用途是把履歷或作品原檔寄給某家公司，並確保那條連結不會永久有效。

## 怎麼用

在素材庫選一個已驗證的版本，詳情頁下方的「限時分享連結」：

1. 選有效期限（1 小時／1 天／3 天／7 天／30 天），可選填開啟次數上限與備註（備註只有你看得到）。
2. 按「建立連結」。網址會立刻顯示，**而且只顯示這一次**。複製後按「我已保存」。
3. 下方列出這個素材所有連結的狀態：有效／已過期／已達次數上限／已撤銷、到期時間、開啟次數、最後開啟時間。有效的連結可以按撤銷，立即失效。

網址長這樣：`https://你的網域/zh/share/<token>`。把 `/zh/` 換成 `/en/` 就是英文版頁面。

收到連結的人看到的是一個頁面：檔名、格式、大小、到期時間，以及一個「下載檔案」按鈕。按下去才會真的取得檔案。

## 安全性設計

- **只存雜湊。** 資料庫存的是 token 的 SHA-256，不是 token 本身。就算整個資料表外流，也沒辦法還原出一條能用的連結；伺服器自己也做不到，所以網址遺失只能重新產生。
- **token 是 32 bytes 亂數**（base64url，43 個字元）。這個長度下猜測不可行，因此沒有另外對 `/share/` 做速率限制。
- **下載用 POST，不是 GET。** 分享連結常常寄在信裡，而 Gmail、Outlook 這類服務會自動跟隨郵件中的連結做安全掃描。落地頁只是讀取（不計次），真正兌換要按按鈕送出表單，掃描器不會 POST，所以不會平白消耗一次開啟額度。
- **開啟計數與上限在同一個 UPDATE 裡完成**，條件與遞增不可分割，所以兩個人同時點最後一次額度，只有一個會成功。
- **每個素材最多 20 條有效連結**，避免腳本無限產生。撤銷或過期的不計入。
- 連結只綁定「一個版本」。切換素材的目前版本不會改變已發出的連結指向的檔案。
- 素材被移到垃圾桶時，它的連結一律失效；還原後除非重新建立，否則不會自動恢復（撤銷是不可逆的）。

## 已知限制

- **撤銷不能召回已經簽發的下載網址。** 按下下載時，伺服器簽發一條 60 秒有效的 Supabase 網址並轉址過去。撤銷會立即擋掉新的兌換，但那 60 秒內已經拿到網址的人仍可下載。
- **「開啟次數」是取得下載網址的次數，不是完成下載的次數。** 對方下載到一半取消也算一次；這個數字不能當成「對方確實讀過」的證據。
- 沒有密碼保護，也沒有記錄開啟者的 IP 或身分。知道網址的人就能取得檔案，這是設計上的取捨：連結本身就是憑證。
- 每次開啟不會寫一筆操作紀錄，只更新連結上的計數與最後開啟時間。建立與撤銷才會寫入 `asset_events`。這是為了避免公開端點把事件表灌爆。
- 轉址到 Supabase 的簽名網址時，對方的網址列會短暫出現 Supabase 網域。

## 資料庫

`supabase/migrations/20260920000600_asset_shares.sql`：

- `asset_shares`：`owner_id`、`asset_id`、`version_id`、`token_hash`（unique，限制為 64 位十六進位）、`label`、`expires_at`、`max_opens`、`opens`、`revoked_at`、`last_opened_at`。啟用 RLS，anon 與 authenticated 完全無權限。
- `asset_create_share()`：檢查版本已驗證、素材未回收、期限介於 1 分鐘到 30 天、每素材 20 條上限，寫入 `share.created` 事件。
- `asset_peek_share()`：唯讀，落地頁用，不計次。
- `asset_redeem_share()`：計次並回傳物件路徑，上限與條件在同一個 UPDATE 判斷。
- `asset_revoke_share()`：只有擁有者可撤銷，重複撤銷不重複寫事件。

**這個 migration 尚未套用到正式 Supabase。** 沒有套用時，素材詳情不會顯示分享區塊（讀取失敗會靜默略過），落地頁則一律顯示「找不到這個分享連結」。

```powershell
npx tsx --test tests/assets.test.ts      # token 形狀與輸入驗證
node scripts/test-assets-sql.mjs         # 含 tests/sql/asset-shares.test.sql
node tests/assets-browser.mjs            # 後台建立、只顯示一次、列表、撤銷
```

資料庫測試涵蓋權限、雜湊格式、期限上下界、未驗證版本、非擁有者、peek 不計次、兌換計次、次數上限、撤銷冪等、過期、素材回收後失效，以及每素材 20 條上限。
